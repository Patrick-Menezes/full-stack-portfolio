Mini Shop

Pretensão e Objetivo

O foco principal foi construir um ecossistema de e-commerce funcional, simulando cenários reais de CRUD e Autenticação. Busquei criar uma plataforma que simula um mini comércio online, onde os usuários podem navegar por um catálogo de produtos usando persistência e adicionar itens ao carrinho. Já como administrador, o foco foi em adicionar novos produtos e gerenciar o estoque.

O que pratiquei

CRUD simples usando .NET 8 e SQL Server Arquitetura MVC Bootstrap
01. Funcionalidades

Uso geral

Implementei um sistema de login que diferencia usuários normais de administradores. Usuários comuns podem navegar e comprar, enquanto administradores têm acesso a funcionalidades de gerenciamento de produtos. O sistema é simples, mas eficaz para demonstrar controle de acesso baseado em funções.

02. Registro e Login

Cadastro de Usuários

Sistema de registro e login simples para aprendizado de busca e persistência de dados. Os usuários podem criar contas, fazer login e acessar funcionalidades específicas com base em suas permissões (usuário comum ou administrador). O foco foi na implementação básica de autenticação e controle de acesso.

03. Funcionalidades do Cliente

Catálogo Dinâmico

Como cliente, o usuário pode navegar pelo catálogo de produtos, visualizar detalhes e adicionar itens ao carrinho.

04. Login

Autenticação de usuários

Para demonstrar a funcionalidade de registro e uso, criei um painel onde mostra os usuários registrados e, a partir disso, o usuário pode fazer login usando as credenciais criadas. O sistema é simples, mas eficaz para demonstrar controle de acesso baseado em funções.

05. Cadastro de Produtos

Uso do Painel de Administração

Como administrador, o usuário pode cadastrar novos produtos, atualizar informações existentes e gerenciar o catálogo de forma eficiente.
