Order Service - CRUD de Ordem de Serviço

Pretensão e Objetivo

Busquei aprender sobre a construção e consumo de APIs RESTful usando .NET 8, com foco em funcionalidades básicas, porém essenciais, como adição, atualização, exclusão e listagem de ordens de serviço.

O que pratiquei

API usando .NET 8, MySQL e Angular 21 Construção de APIs e Swagger Consumo de APIs em Angular Bootstrap
01. Iniciando programas

Uso geral

Demonstração da inicialização de ambos os projetos e comunicação entre eles. O vídeo mostra o processo de execução do backend e frontend, destacando a interação entre os dois e a configuração inicial necessária para colocar o sistema em funcionamento.

02. Adicionando Serviços

Usando POST

Demonstração da utilização do método POST para adicionar novos serviços ao sistema. O vídeo mostra o processo de criação de um novo serviço, incluindo o preenchimento dos campos necessários e a submissão do formulário, tanto pelo Swagger quanto pelo frontend.

03. Removendo um serviço

Métodos GET e DELETE

Demonstrando o uso dos métodos para recuperar uma ordem de serviço específica usando GET e a remoção de um serviço usando DELETE. O vídeo mostra como buscar detalhes de um serviço existente e, em seguida, como excluir um serviço do sistema, destacando a funcionalidade de gerenciamento de serviços.

04. Atualização

Métodos PUT e PATCH

Demonstração do processo de atualização de um serviço usando os métodos PUT e PATCH. O vídeo mostra como modificar as informações de um serviço existente, destacando a diferença entre os dois métodos: PUT para substituição completa e PATCH para atualização parcial dos dados do serviço, incluindo casos de erro de requisição quando o formulário é mal preenchido.
